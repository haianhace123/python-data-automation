# Python Data Automation Tool



A Python project for automating Excel/CSV data cleaning tasks.



## Features



- Remove duplicate rows

- Fill missing values

- Standardize column names

- Export cleaned Excel files

- Simple automation workflow



## Technologies



- Python

- pandas

- openpyxl



## Project Structure



python-data-automation/

│

├── data/

├── output/

├── src/

├── requirements.txt

└── README.md



## How to Run



Install dependencies:



pip install -r requirements.txt



Run the script:



cd src

python main.py
